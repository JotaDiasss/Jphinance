# Jphinance 1.0

App pessoal de finanças em SwiftUI para macOS 13 ou superior. Inclui orçamento, agenda, gastos mensais, metas e caixinhas.

Abra Jphinance.app no Mac com o compilador Swift e o SDK de macOS instalados. Na primeira execução, o iniciador compila as fontes em Jphinance.app/Contents/Resources/Sources.

O app funciona localmente. Para habilitar o serviço de sincronização compatível, configure JphinanceSyncHost em Contents/Resources/NativeInfo.plist com o domínio do seu serviço.

## Arquivos

Baixe e descompacte Jphinance-1.0.zip para obter o pacote completo do app, com o ícone, o iniciador executável e o código-fonte. Os arquivos Swift desta pasta também estão disponíveis para consulta no GitHub.
